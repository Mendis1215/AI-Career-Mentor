1. Project Title - AI Career Mentor Platform

2. Project Tagline: Empowering university students with personalized AI guidance to become internship and career ready.

3. Problem Statement: University students often know what career they want to pursue, but they struggle to determine whether they are actually ready for internships or full-time jobs.

Students face several common challenges:

They don't know which technical skills they should learn.
They cannot identify the skills they are missing.
They are unsure whether their GitHub profile is professional enough.
They don't know how to improve their LinkedIn profile.
They are confused about which certification courses are valuable.
They don't know what projects they should build.
They don't know whether they are ready for internship interviews.
They receive generic advice from websites instead of personalized guidance.

As a result, many students spend time learning the wrong things or applying for internships before they are ready.

4. Proposed Solution - The AI Career Mentor Platform is a web application that provides personalized career guidance for university students.

The system collects information about each student, including:

Degree Program
Academic Year
Career Goal
Current Skills
Skill Levels
Projects
Certifications
GitHub Profile
LinkedIn Profile

The backend analyzes this information against the requirements of the student's chosen career.

The AI then provides personalized recommendations, including:

Skill Gap Analysis
Internship Readiness Analysis
Learning Roadmap
Certification Recommendations
Project Suggestions
GitHub Improvement Suggestions
LinkedIn Improvement Suggestions
Resume Feedback
AI Career Mentor Chat

5. Vision Statement: To build an intelligent AI-powered career mentoring platform that helps university students continuously evaluate, improve, and prepare themselves for internships and professional careers through personalized analysis and guidance.

6. Mission Statement
Our mission is to help students:

Understand their current skill level.
Identify missing skills.
Learn the right technologies in the correct order.
Build stronger portfolios.
Prepare for internship interviews.
Increase their confidence before applying for jobs.

8. Core Objectives

The system should enable students to:

Create a personalized career profile.
Assess their technical skills.
Select a target career.
Identify missing skills.
Track internship readiness.
Receive AI-generated career guidance.
Improve GitHub and LinkedIn profiles.
Discover appropriate certification courses.
Follow a personalized learning roadmap.

The system should enable administrators to:

Manage degree programs.
Manage career paths.
Manage skills.
Manage learning resources.
Manage certification recommendations.
Update AI knowledge without modifying source code.

10. Expected Outcomes

For Students:
Better understanding of their career readiness.
Clear learning direction.
Stronger internship preparation.
Improved professional profiles.
Personalized AI guidance.

For Administrators:
Easy content management.
No need to modify source code to update careers, skills, or certifications.
Centralized management of career-related information.

11. Success Criteria

The project will be considered successful if it can:

Analyze a student's profile correctly.
Identify missing skills accurately.
Generate a personalized learning roadmap.
Calculate internship readiness consistently.
Provide AI responses grounded in the student's data and the knowledge base.
Allow administrators to manage platform content without changing the application's code.
